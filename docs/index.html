Open Data & Code
Get the Data, the Pipeline and the Documentation

Two analysis-ready datasets are released from the gold layer, one folder per farm (Farm A–Farm H). Farm, animal and life-number identifiers are pseudonymised; raw (bronze) data is not shared.

SOS24h — daily dataset

One row per cow per day: time budgets (eating, ruminating, lying, standing, walking, inactive), lactation stage, health and reproduction records, and daily farm climate (THI).

Dataset DOI: added on publication

SOS2h — 2-hour dataset

The same cows in twelve 2-hour bins per day, built from the 15-minute sensor series, with 2-hourly farm climate. Daily totals in SOS24h equal the sum of these bins.

Dataset DOI: added on publication

Pipeline code

The Databricks notebooks that build bronze, silver and gold, the rulebooks that declare every cleaning rule, and the export that writes SOS24h and SOS2h.

Data Engineering
Bronze → Silver → Gold Cleaning Pipeline

All cleaning logic declared in 5 shared Delta metadata tables — never hardcoded in notebooks. Silver keeps all rows; problems become Warnings array annotations, never silent drops.

⬡ Bronze Layer — Raw Ingestion
1
Four source datasets
ReferenceData (Parquet), SensorData (Parquet, 23 folders), THI (CSV), CalendarData (CSV, 2 batches). Read-only — never modified.
2
Calendar data recovery
DryoffEvent and CalvingEvent CSVs excluded from original ingestion — re-ingested from blob storage. Provides actual lactation boundary dates.
3
63 positional columns mapped
ReferenceData had no column headers — all 63 columns identified by position and named. ObservationType folder structure documented.
⬡ Silver Layer — Cleaning
1
PascalCase normalisation
All column names, ObservationType folder names, and metadata fields normalised to PascalCase. Source was camelCase with mixed underscores.
2
Type casting & range validation
Dates → date/timestamp. Numerics → double. BCS capped at 5. Values flagged with Warnings array — never silently dropped.
3
Deduplication
SensorData: 9.5M exact duplicates removed. Calendar batches: 36.7K overlap duplicates removed. Corrupt dates (year < 2000) dropped.
4
Farm notes → English glossary
94 terms in Notes and IndividualAttention columns mapped to English. Applied in Gold as 61 boolean condition flags.
⬡ Gold Layer — Enrichment
1
3-stddev outlier filter
Applied per ObservationType before daily aggregation. Translated from original Scala research notebooks. Removes statistically extreme readings.
2
1.2B → 2.5M daily pivot
Raw sensor readings aggregated to one row per animal per day. Values already in minutes. Impossible daily totals (> 1440 min) nulled.
3
Lactation window construction
DryoffEvent dates replace estimated LactationEnd for 801 of 1,648 windows. Extended 21 days pre-calving for transition cow analysis.
4
158-column GoldMaster join
All 7 gold tables joined via left joins — no data dropped. DaysInMilk, LactationPhase, CalvingSeason, PreCalvingWeek derived columns added.
